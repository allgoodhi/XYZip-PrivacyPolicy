## 简体中文

**最后更新：2026 年 9 月**

XYZip 与 XYZip Pro（以下统称「本软件」）**不收集、不存储、不传输任何个人信息**。

### 不联网

本软件不访问网络。它的安装包不声明任何网络能力，程序中也不包含任何网络访问代码。
本软件不含遥测、统计、崩溃上报或广告组件。

本软件使用的唯一进程间通信是**本机命名管道**，用途只有一个：当你第二次启动本软件时，
把要打开的文件交给已经打开的窗口，避免开出多个窗口。它不跨越本机边界。

### 你的文件

本软件在你的电脑上读写文件，位置**完全由你指定**——通过文件对话框、拖放，或资源管理器右键菜单。
本软件不会把这些文件或它们的内容、文件名发送到任何地方。

### 设置

本软件的设置（界面语言、外观、压缩预设、备份任务等）保存在你自己电脑的用户配置中，不会离开这台电脑。

本软件还会记住你最近打开过的压缩包，以便在「文件 → 最近打开」中再次打开它们。这份列表就是这些文件的路径，同样保存在你自己电脑上、不会离开这台电脑，最多保留 10 条。你可以随时关闭这项记录，或清空已有的记录：**设置 → 记录**。关闭它会连同已经记下的一起清除，而不只是不再显示。

搜索压缩包时，本软件还会记下已经读过的那些压缩包里有哪些文件名，好让同一个文件夹的第二次搜索不必重新打开每个压缩包。它**只记录搜索时已经读过的压缩包**，不会自己去扫描磁盘上的任何东西。这份记录同样只存在你自己电脑上，可以在同一处关闭或清除。

**备份任务不保存密码。** 加密的备份任务无法由计划任务自动运行，因为运行时没有人可以提供密码。

### Cookie 与第三方

本软件不使用 Cookie，不与任何第三方共享数据——因为它不产生任何可供共享的数据。

### 儿童

本软件不面向特定年龄群体，也不收集任何人的信息，包括儿童的信息。

### 本政策的变更

若本政策发生变更，更新后的版本会发布在本页，并更新上方的「最后更新」日期。

## English

**Last updated: September 2026**

XYZip and XYZip Pro (“the software”) **do not collect, store or transmit any personal information**.

### No network access

The software does not access the network. Its package declares no network capability, and the
program contains no network code. It contains no telemetry, analytics, crash reporting or
advertising.

The only inter-process communication the software uses is a **local named pipe**, for one purpose:
when you launch the software a second time, it hands the files you opened to the window that is
already open, instead of opening another one. It does not cross the machine boundary.

### Your files

The software reads and writes files on your computer, at locations **you choose** — through file
dialogs, drag and drop, or the Explorer context menu. It does not send those files, their contents,
or their names anywhere.

### Settings

The software's settings — interface language, appearance, compression presets, backup jobs — are
stored in your own user profile on that computer and never leave it.

The software also remembers the archives you opened recently, so that you can open them again
from File → Recently opened. That list is the paths of those files. It is kept in the same place,
never leaves your computer, and holds at most 10 entries. You can switch the recording off, or
clear what has been recorded, at any time under **Settings → History**. Switching it off clears
what has already been recorded as well, rather than only hiding it.

When you search inside archives, the software also records the file names in the archives it has
already read, so that searching the same folder a second time does not have to reopen every one.
It records **only archives a search has already read**; it never scans anything on the disk of its
own accord. That record is likewise kept only on your own computer, and can be switched off or
cleared in the same place.

**Backup jobs do not store passwords.** An encrypted backup job cannot be run by the task scheduler,
because there is nobody there to supply the password when it runs.

### Cookies and third parties

The software uses no cookies and shares no data with third parties, because it produces no data to
share.

### Children

The software is not directed at any particular age group, and collects no information from anyone,
children included.

### Changes to this policy

If this policy changes, the updated version will be published on this page and the “Last updated”
date above will change with it.
